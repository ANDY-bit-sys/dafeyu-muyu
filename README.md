# 大肥鱼木鱼

蓝发大肥鱼陪你敲木鱼，简洁、解压。点击木鱼或按空格，功德加一。

在线试玩：https://andy-bit-sys.github.io/dafeyu-muyu/

- 支持手机横竖屏、木鱼音效、静音、夜间模式与本地记录。
- 右上角下载图标提供 Windows EXE 和安卓 APK，两者均可离线使用。
- Windows 和安卓的悬浮窗都只显示角色、木鱼与坐垫，背景透明，没有网址栏、标题栏、常驻功德或底条；敲击时保留短暂的「功德 +1」飘字。点击木鱼敲击，拖动角色移动，右键／长按可设置或关闭。
- 电脑网页悬浮窗按钮唤起 Windows 透明桌宠。首次下载并运行新版 EXE 建立关联，浏览器询问时选择打开；之后可从网页唤起，重复打开会恢复同一个小窗。应用未运行时只打开桌宠，关闭桌宠退出该进程；右键可打开主界面查看功德。
- 手机跨应用悬浮由安卓应用提供：允许「显示在其他应用上层」后可跨应用显示，长按角色打开菜单或关闭。手机网页的按钮提供安装入口。
- 网页、EXE 和 APK 都有爱心投喂入口，显示原文与合十动图；选择「好呀」后才显示提供的微信收款码。
- 安卓应用底部「轻震动」提供开关与测试，敲击优先使用系统触感反馈，并根据设备能力提供兼容处理。

这是静态网页，直接从 main 分支根目录发布到 GitHub Pages，入口为 `index.html`，`.nojekyll` 用于保留原始静态文件。`release.json` 记录当前发布批次及运行资源 SHA-256。

网页版与应用版分别保存记录，应用主界面与其悬浮窗共享功德和声音设置。安卓 1.1.1，最低 Android 8.0。Windows 已实际运行检查；安卓已在 Android 14 模拟器检查覆盖升级、投喂、悬浮窗及振动调用，尚未在实体手机检查震动体感。实际振动受硬件与系统触感设置影响。

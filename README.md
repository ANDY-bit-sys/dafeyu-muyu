# 大肥鱼木鱼

蓝发大肥鱼陪你敲木鱼，简洁、解压。点击木鱼或按空格，功德加一。

在线试玩：https://andy-bit-sys.github.io/dafeyu-muyu/

- 支持手机横竖屏、木鱼音效、静音、夜间模式与本地记录。
- 右上角下载图标提供 Windows EXE 和安卓 APK，两者均可离线使用。
- 网页悬浮窗按钮引导安装对应应用。Windows 可拖动、敲击和收起到托盘；安卓允许「显示在其他应用上层」后可跨应用悬浮，长按角色打开菜单或关闭。
- 网页、EXE 和 APK 都有爱心投喂入口，显示原文与合十动图；选择「好呀」后才显示提供的微信收款码。
- 安卓应用底部「轻震动」提供开关与测试，敲击优先使用系统触感反馈，并根据设备能力提供兼容处理。

这是静态网页，直接从 main 分支根目录发布到 GitHub Pages，入口为 `index.html`，`.nojekyll` 用于保留原始静态文件。`release.json` 记录当前发布批次及运行资源 SHA-256。

网页版与应用版分别保存记录，应用主界面与其悬浮窗共享功德和声音设置。安卓 1.1.0，最低 Android 8.0。Windows 已实际运行检查；安卓已在 Android 14 模拟器检查覆盖升级、投喂、悬浮窗及振动调用，尚未在实体手机检查震动体感。实际振动受硬件与系统触感设置影响。
